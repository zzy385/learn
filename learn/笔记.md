# Linux 命令速查表（D1 10/1）

## 目录与文件
- `pwd`：显示当前目录 
- `ls` / `ls -la`：列出文件 / 详细列出（含权限）
- `cd 目录`：进入目录
- `mkdir -p a/b`：一次创建多层目录
- `touch 文件`：创建空文件

## 查看内容
- `cat 文件`：显示整个文件
- `head -n 5 文件`：看前 5 行
- `tail -n 5 文件`：看最后 5 行
- `wc -l 文件`：数行数

## 复制 / 移动 / 删除
- `cp 源 目标`：复制
- `mv 旧名 新名`：改名 / 移动
- `rm 文件`：删除（不可恢复！）

## 权限
- `chmod 644 文件`：改权限（r=4 w=2 x=1）
- `ls -l` 输出 `-rw-r--r--` = 类型 + 本人 + 同组 + 其他人

## 其他
- `echo "文字" > 文件`：写入（覆盖）
- `echo "文字" >> 文件`：追加
- `Ctrl+C`：中断当前命令
